📋 STRUCTURE D'UN PARAMÈTRE NUMÉRIQUE
────────────────────────────────────────────────────────────────────────────

struct NumericParam {
    int32_t     minValue;           // Ex: 1
    int32_t     maxValue;           // Ex: 200
    int32_t     step;               // Ex: 1 (incrément par cran)
    int32_t     value;              // Ex: 120 (valeur courante)
    const char* unit;               // Ex: "BPM" (affiché au ESP32)
};

Exemple complet :
  static NumericParam kBpmParam = { 1, 200, 1, 120, "BPM" };

🔌 LES 3 ÉLÉMENTS D'UNE INTÉGRATION
────────────────────────────────────────────────────────────────────────────

1️⃣  DÉCLARATION du NumericParam
     static NumericParam kMyParam = { min, max, step, value, "unit" };

2️⃣  FONCTION CALLBACK (Apply)
     static void ApplyMyParam(int32_t index) {
         float val = static_cast<float>(kMyParam.value);
         // synth.SetSomething(val);
     }

3️⃣  INTÉGRATION AU MENU (MenuNode)
     { "My Param", COLOR_DEFAULT, nullptr, 0, ApplyMyParam, 0, &kMyParam }
                                                      ↑              ↑
                                            callback function   NumericParam pointer

⚙️  CONVERSIONS COURANTES
────────────────────────────────────────────────────────────────────────────

De int32_t vers float :
  float val = static_cast<float>(kMyParam.value);

Pourcentage (0-100%) vers ratio (0.0-1.0) :
  float ratio = kMyParam.value / 100.0f;

Millisecondes vers secondes :
  float sec = static_cast<float>(kMyParam.value) / 1000.0f;

Cents vers ratio fréquence :
  float ratio = powf(2.0f, kMyParam.value / 1200.0f);

Degrés (0-360°) vers ratio (0.0-1.0) :
  float phase = kMyParam.value / 360.0f;

Valeur bipolaire (-100%..+100%) vers ratio (-1.0..1.0) :
  float bipolar = kMyParam.value / 100.0f;  // reste négatif si nécessaire

   • Valeur augmente/diminue
   • Callback ApplyXxx() appelé
   • Transmission ESP32 en temps réel

   • Valeur conservée
   • Sortie du mode édition
   • Retour au menu normal

5. OU Appuyer HOME → ANNULATION
   • Valeur revient à l'original
   • Sortie du mode édition

🚨 ERREURS COURANTES
────────────────────────────────────────────────────────────────────────────

Erreur : "redeclaration of 'kBpmParam'"
Cause : Deux déclarations de kBpmParam
Fix : Supprimer l'ancienne (ligne 258), garder la nouvelle

Erreur : "undefined reference to 'ApplyMyParam'"
Cause : La fonction n'existe pas ou est commentée
Fix : Vérifier que la fonction est déclarée AVANT le MenuNode qui l'utilise

Erreur : "member initialization is out of order"
Cause : Les champs du MenuNode ne sont pas dans le bon ordre
Fix : Vérifier l'ordre : label, color, children, childCount, onSelect, selectedIndex, numeric

Menu n'affiche pas de paramètre éditable
Cause : .numeric = nullptr au lieu de &kXxxParam
Fix : Ajouter .numeric = &kXxxParam à la fin du MenuNode

Paramètre n'a aucun effet
Cause : La fonction ApplyXxx() est vide ou ne fait rien
Fix : Implémenter ApplyXxx() avec // synth.SetSomething(...)

📊 PARAMÈTRES STANDARDS
────────────────────────────────────────────────────────────────────────────

// Temps (ms)        [min, max, step, initial, unit]
{ 1, 5000, 10, 50, "ms" }           // Attack
{ 1, 5000, 10, 200, "ms" }          // Decay
{ 1, 5000, 10, 300, "ms" }          // Release

// Fréquence (Hz)
{ 20, 20000, 50, 1000, "Hz" }       // Cutoff, LFO rate
{ 1, 500, 1, 10, "Hz" }             // LFO

// Pitch (semitones)
{ -24, 24, 1, 0, "st" }             // Coarse, Fine

// Pourcentage
{ 0, 100, 1, 50, "%" }              // Volume, Resonance, Dry/Wet
{ 0, 100, 5, 0, "%" }               // Drive (pas plus rapide)

// Bipolaire (±100%)
{ -100, 100, 5, 0, "%" }            // Envelope modulation

// Degrees
{ 0, 360, 5, 0, "°" }               // LFO phase

// Canal MIDI
{ 1, 16, 1, 1, "ch" }               // MIDI Channel

// BPM
{ 1, 200, 1, 120, "BPM" }           // Tempo
